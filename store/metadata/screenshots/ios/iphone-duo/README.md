# iPhone Duo screenshots

ABYSM's `APP_IPHONE_DUO` set contains five 1398×2034 RGB marketing frames
composed from gameplay captured on the Duo simulator's outer display.

With `IOS_UPLOAD_SCREENSHOTS` on, PNGs here (1–10, outer screen 1398×2034 or
inner screen 2007×2853) go to App Store Connect with the iPhone and iPad sets, in
file-name order, as RGB copies ([store-release's ABYSM flow](https://github.com/apoorvdarshan/store-release/blob/v0.4.0/store_release/flows/abysm/asc_release.py)). Any other size
fails the run before anything is uploaded.
