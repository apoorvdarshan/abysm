# iPhone Duo screenshots

Optional, and empty: ABYSM has no iPhone Duo screenshots, so the `APP_IPHONE_DUO`
set in App Store Connect is left alone.

With `IOS_UPLOAD_SCREENSHOTS` on, PNGs here (1–10, outer screen 1398×2034 or
inner screen 2007×2853) go to App Store Connect with the iPhone and iPad sets, in
file-name order, as RGB copies ([store-release's ABYSM flow](https://github.com/apoorvdarshan/store-release/blob/v0.3.0/store_release/flows/abysm/asc_release.py)). Any other size
fails the run before anything is uploaded.
