# ABYSM Marketing Assets

Flattened assets for App Store listings, press materials, social posts, and other
marketing work.

## Structure

- `app-store/iphone/screenshots/` — original landscape iPhone captures
- `app-store/iphone/mockup-ready/` — clockwise-rotated iPhone captures for
  mockup tools that rotate imported images
- `app-store/iphone/mockups/` — finished iPhone marketing images
- `app-store/ipad/screenshots/` — original landscape iPad captures
- `app-store/ipad/mockup-ready/` — clockwise-rotated iPad captures for mockup
  tools that rotate imported images
- `app-store/ipad/mockups/` — finished iPad marketing images
- `paywall.png` — in-app purchase screen reference

The app icon is not duplicated here. Use
`Abysm/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.

EXIF and XMP metadata have been removed from the copies in this directory.
Color profiles are retained where present.
